# Plan Execution Mode

Use this internal mode when a written plan already exists and should be executed critically and methodically.

## Goal

Treat the plan as a strong guide, not an excuse to stop thinking. Review it, execute it, verify continuously, and stop when the plan is wrong or incomplete.

## Operating Rules

- Read the full plan before starting.
- Raise critical gaps before execution instead of guessing through them.
- Execute tasks in order unless the plan explicitly supports reordering.
- Run the required checks at each verification point.
- Escalate when repeated failures or plan defects indicate the plan should change.

## Escalation

If a plan exists but task slices are mostly independent and delegated execution would improve speed without reducing quality, switch into `same-session delegated execution` mode.
